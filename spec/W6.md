# Wave 6: optimization

Read CONTRACT.md first. This wave adds **no language**. You make the code your compiler emits faster, without
breaking anything.

## The benchmarks

- `spec/bench/` holds 8 C programs, each with its `.expected` stdout (exit status 0): fib, sieve, matmul, sort,
  bintree, fannkuch, crc and vm.
  - They use only W1-W5 features and no floats.
  - Each runs for about 0.2 to 0.6 s when compiled with `gcc -O0`.
- You may time them as much as you like.
- **The hidden runner times variants of these programs, not these files.** The variants are the same programs with
  other constants (the `#define` values: sizes, seeds, rotations), so recognizing the visible text gains nothing (and
  is forbidden: CONTRACT.md rule 4).

## The score

- **Per program:** compile the hidden variant with your compiler and with `gcc -O0`.
  - Run your program and gcc's alternately, 5 times each, one at a time with nothing else running, both in the same
    sandbox.
  - Take each one's median wall time. ratio = yours / gcc -O0's.
- **Failures.** A program that fails to compile, link, finish in time (the greater of 20 s and 20 × gcc's time), or
  print the expected output counts as ratio 20.
- **W6 score** = the geometric mean of the 8 ratios. Lower is better, and 1.0 means you match `gcc -O0`.
- **The regression gate.** The W6 run also runs the hidden W1-W5 suite with your W6 compiler. Any test that your W5
  hand-in passed and the W6 compiler fails is a regression. The gate passes only with zero regressions, and the
  hidden run prints how many there are.

## Allowed

Anything inside your compiler: register allocation, keeping values in registers, constant folding and propagation,
strength reduction, peephole passes, better instruction selection, inlining, loop work, and so on.

## Not allowed

Calling any external program (CONTRACT.md rule 1), or recognizing specific programs and emitting code that was not
derived from their source.
