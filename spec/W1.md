# Wave 1: integers, expressions, locals, control flow, functions

Read CONTRACT.md first. This wave starts the compiler. Everything later builds on it.

## In scope

- **Type.** `int`, plus `void` as a function's return type.
  - Integer constants are decimal, hex (`0x2a`) or octal (`052`), and fit in `int`.
- **Expressions:**
  - arithmetic: `+ - * / %`, unary `- + !`;
  - comparison: `== != < <= > >=`;
  - logic: `&& ||`, short-circuit;
  - assignment: `= += -= *= /= %=`;
  - increment and decrement: `++` and `--`, both prefix and postfix;
  - also `?:`, the comma operator and parentheses.
  - Division truncates toward zero. Evaluation order is the usual left-to-right where C defines it, and tests do not
    depend on it where C leaves it open.
- **Locals.** Block-scope `int` variables:
  - declared anywhere in a block, with or without an initializer;
  - several in one declaration (`int a = 1, b;`);
  - declared in a `for` init clause;
  - nested blocks and shadowing.
- **Statements.** `if`/`else`, `while`, `do … while`, `for` (any clause may be empty), `break`, `continue`,
  `return`, expression statements, empty statements and blocks.
- **Functions:**
  - definitions with `int` parameters (tests may use more than six, which go on the stack), in prototype form
    (`int f(int a, int b)`) or the old K&R form (`int f(a, b) int a; int b; { … }`, and `int f(a) { … }`, where an
    undeclared parameter is `int`);
  - forward declarations, recursion and mutual recursion;
  - `int main()`, `int main(void)`; main's return value is the exit status.
- **Calling libc without headers.** W1 has no preprocessor, so a test that prints declares what it calls, for
  example `int printf(const char *fmt, ...);`, `int puts(const char *s);`, `int putchar(int c);`, `void exit(int);`,
  `void abort(void);`.
  - So already in W1 your compiler must parse prototypes with pointer, `const`, `char` and `...` parameters, with or
    without `extern` in front (`extern void abort (void);`): a function prototype may always carry `extern`.
  - It must also pass **string literals as call arguments** (emitted in `.rodata`) and call a variadic libc function
    with integer arguments (`%al` = 0).

## Categories (hidden-run lines)

- `W1 functions`: calls to the test's own functions, or recursion.
- `W1 control`: if/loops/break/continue.
- `W1 expressions`: everything else.

## Not yet

Pointers, arrays, `char` variables, globals and string literals used other than as call arguments are W2. sizeof,
structs and initializer lists are W3. Any `#` line is W4. switch, goto, casts, unsigned, long, short, bitwise
operators, `static` and `extern` on variables and on function definitions, and floats are W5. GNU extensions
(`__builtin_*` other than the va intrinsics, statement expressions, `typeof`, `__attribute__`, …) are W5's `gnu`
category, never W1.
