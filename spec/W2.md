# Wave 2: pointers, arrays, strings, globals, char

Read CONTRACT.md first. Everything in W1 stays in scope and is tested again (regressions).

## In scope

- **Pointers:**
  - `&` and unary `*`, pointers to `int`, `char` and pointers;
  - pointer arithmetic scaled by the pointee size, `p - q` between pointers, and pointer comparisons;
  - `0` as the null pointer, and `void *` in prototypes;
  - pointer parameters and returns, and passing addresses of locals.
- **Arrays:**
  - one- and multi-dimensional arrays of int, char and pointers, local or global;
  - subscripts, which work on both arrays and pointers;
  - array-to-pointer decay and array parameters with a constant size or none (`int a[]`, `int a[10]`,
    `int m[][3]`). A parameter whose size is not a constant (`int b[n]`, `int b[a++]`) is a variable-length array:
    W5's `vla` category.
  - Arrays are filled by assignment in this wave: brace initializers are W3.
- **Strings.** String literals as values (`char *s = "abc";` inside a function), all the usual escapes (`\n \t \\ \"
  \' \0 \x41 \101`), and adjacent literals concatenated.
- **Globals.** File-scope variables: zero-initialized, or initialized with an integer constant (`int g = 5;`). Use
  and assign them from any function.
- **`char`.** A signed 1-byte type: char variables and arrays, character constants (`'a'`, `'\n'`), and the promotion
  to int in expressions.

## Categories

`W2 strings`, `W2 char`, `W2 globals`, `W2 arrays`, `W2 pointers`. A test's category is the first one in this list
that it uses, and it may use the rest.

## Not yet

These are W3:
- `sizeof`;
- `char s[] = "abc"` and any `{...}` initializer;
- globals initialized with an address or a string (`char *p = "x";` at file scope);
- structs.
